# Licensing

This project is licensed under `GPL-3.0-or-later`.

The repository includes the full GPLv3 text in `LICENSE`. Source files use SPDX identifiers where practical:

```text
SPDX-License-Identifier: GPL-3.0-or-later
```

## Why GPL-3.0-or-later?

`GPL-3.0-or-later` means recipients may use the project under GPL version 3 or any later version published by the Free Software Foundation. This is more flexible than `GPL-3.0-only`.

## If you prefer GPL-3.0-only

Change SPDX identifiers from:

```text
GPL-3.0-or-later
```

to:

```text
GPL-3.0-only
```

and update the README license section accordingly.
